## Timeline

### v5.x

- **2026-05-02** — [Announcing v5.7.0](/docs/release-notes/v5.7.0): A maintenance release featuring the fully implemented no-unused-state rule and LTS maintenance mode.
- **2026-04-29** — [Announcing v5.6.0](/docs/release-notes/v5.6.0): A major release featuring core API refactoring, kit API simplification, new rules, and class component support deprecation.

### v4.x

- **2026-04-01** — [Announcing v4.2.1](/docs/release-notes/v4.2.1): A major release introducing a dedicated JSX plugin, new utility package for custom rules, and flattened rule naming.

### v3.x

- **2026-03-16** — [Announcing v3.0.0](/docs/release-notes/v3.0.0): A major release with new rules ported from eslint-plugin-react-hooks, consolidated packages, and ESLint v10 support.

### v2.x

- **2025-09-26** — [Announcing v2.0.0](/docs/release-notes/v2.0.0): A major release embracing modern JavaScript standards with powerful new rules and DX improvements.
