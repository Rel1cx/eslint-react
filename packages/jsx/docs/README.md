Contiguous TypeScript type-expression ancestors are skipped, and the node is unwrapped before the comparison; expressions nested inside an argument are not considered.                                                            |
| [isElement](functions/isElement.md)                                             | Check if the node is a `JSXElement` or `JSXFragment`.                                                                                                                                                                                                                                                                                                 |

For namespaced names, the local part is checked (ex: `rect` in `<svg:rect>`). Member-expression names (ex: `<foo.Bar>`) are not host elements.                                  |
| [isInsideCreateElementProps](functions/isInsideCreateElementProps.md)           | Check if the node's closest `ObjectExpression` ancestor is the props object (the second argument) of its nearest enclosing `createElement` call. | [isMeaningfulChild](functions/isMeaningfulChild.md)                             | Check if the child carries content for the "meaningful children" semantics.                                                                                                                                                                                                                                                                           |
| [isPaddingWhitespace](functions/isPaddingWhitespace.md)                         | Check if the node is whitespace-only `JSXText` that this module treats as padding: it cleans to nothing (see [collapseMultilineText](functions/collapseMultilineText.md)) and contains a line feed (`\n`).                                                                                                                                            |
| [isWhitespaceText](functions/isWhitespaceText.md)                               | Check if the node is whitespace-only `JSXText`, based on its raw source text.                                                                                                                                                                                                                                                                         |
| [parseCreateElementCall](functions/parseCreateElementCall.md)                   | Parse a `createElement` call into its positional arguments.                                                                                                                                                                                                                                                                                           |
