# @eslint-react/jsx

## Interfaces

| Interface                                            | Description                    |
| ---------------------------------------------------- | ------------------------------ |
| [CreateElementCall](interfaces/CreateElementCall.md) | A parsed `createElement` call. |

## Type Aliases

| Type Alias                                       | Description                                           |
| ------------------------------------------------ | ----------------------------------------------------- |
| [AttributeTest](type-aliases/AttributeTest.md)   | A test used to select a `JSXAttribute`.               |
| [AttributeValue](type-aliases/AttributeValue.md) | The structural value of an attribute.                 |
| [ElementTest](type-aliases/ElementTest.md)       | A test that determines whether a JSX element matches. |

## Variables

| Variable                                          | Description                                                                 |
| ------------------------------------------------- | --------------------------------------------------------------------------- |
| [isAttributeNamed](variables/isAttributeNamed.md) | Check if the node is a `JSXAttribute` with the given full name.             |

| [findCreateElementProp](functions/findCreateElementProp.md)                     | Find a statically named direct property in the props object of a `createElement` call.                                                                                                                                                                                               |

| [getChildren](functions/getChildren.md)                                         | Get the children of a JSX element or fragment after removing syntactic JSX artifacts: padding whitespace, empty expression containers, and empty string literal expressions.                                                                                                         |
| [getElementFullType](functions/getElementFullType.md)                           | Get the string representation of a JSX element's type.                                                                                                                                                                                                                               |
| [getElementSelfType](functions/getElementSelfType.md)                           | Get the self name (last dot-separated segment) of a JSX element type.                                                                                                                                                                                                                |
| [getMeaningfulChildren](functions/getMeaningfulChildren.md)                     | Get the children of a JSX element or fragment that are not syntactically empty.                                                                                                                                                                                                      |
| [hasAnyAttribute](functions/hasAnyAttribute.md)                                 | Check if the element has at least one of the given direct attributes.                                                                                                                                                                                                                |
| [hasAttribute](functions/hasAttribute.md)                                       | Check if the element has a direct attribute with the given full name.                                                                                                                                                                                                                |
| [hasEveryAttribute](functions/hasEveryAttribute.md)                             | Check if the element has all of the given direct attributes.                                                                                                                                                                                                                         |
| [hasMeaningfulChildren](functions/hasMeaningfulChildren.md)                     | Check if the element has at least one syntactically non-empty child.                                                                                                                                                                                                                 |
| [isCreateElementCall](functions/isCreateElementCall.md)                         | Check if the node is a call to a `createElement` API.                                                                                                                                                                                                                                |
| [isCreateElementChildrenArgument](functions/isCreateElementChildrenArgument.md) | Check if the node is passed as a children argument (the third argument or later) of a `createElement` call.                                                                                                                                                                          |
| [isElement](functions/isElement.md)                                             | Check if the node is a `JSXElement` (or `JSXFragment`), optionally matching a given test.                                                                                                                                                                                            |
| [isEmptyExpressionContainer](functions/isEmptyExpressionContainer.md)           | Check if the node is an empty expression container (`{}`, `{/* comment */}`).                                                                                                                                                                                                        |
| [isEmptyStringExpression](functions/isEmptyStringExpression.md)                 | Check if the node is an empty string literal expression (`{""}`).                                                                                                                                                                                                                    |
| [isFragmentElement](functions/isFragmentElement.md)                             | Check if the node is a React Fragment element.                                                                                                                                                                                                                                       |
| [isHostElement](functions/isHostElement.md)                                     | Check if the node is a host (intrinsic / DOM) element, that is, a `JSXElement` whose tag name starts with a lowercase letter (ex: `<div>` vs `<MyComponent>`). For namespaced names, the local part is checked (ex: `rect` in `<svg:rect>`).                                         |
| [isInsideCreateElementProps](functions/isInsideCreateElementProps.md)           | Check if the node is directly inside the props object (the second argument) of a `createElement` call, that is, its closest `ObjectExpression` ancestor is the props object itself. Nodes nested deeper (ex: inside an object nested in the props object) are not considered inside. |
| [isPaddingWhitespace](functions/isPaddingWhitespace.md)                         | Check if the node is whitespace padding that React would trim away during rendering, that is, a `JSXText` node that cleans to nothing (see [collapseMultilineText](functions/collapseMultilineText.md)) and contains a newline.                                                      |
| [isWhitespaceText](functions/isWhitespaceText.md)                               | Check if the node is whitespace-only text.                                                                                                                                                                                                                                           |
| [parseCreateElementCall](functions/parseCreateElementCall.md)                   | Parse a `createElement` call into its positional arguments.                                                                                                                                                                                                                          |
| [resolveAttributeStaticValue](functions/resolveAttributeStaticValue.md)         | Collapse a resolved attribute value to a plain JavaScript value when possible.                                                                                                                                                                                                       |
| [resolveAttributeValue](functions/resolveAttributeValue.md)                     | Resolve a `JSXAttribute` or `JSXSpreadAttribute` into an [AttributeValue](type-aliases/AttributeValue.md) descriptor.                                                                                                                                                                |
